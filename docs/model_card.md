# ForgeLens Model Card

Status: under development. No portfolio model or research performance is
currently claimed.

The current `TinyJointDetector` is a pipeline baseline with image-level and
pixel-level heads. It has only been smoke-trained on blank-canvas fictional
fixtures. It must not be used for decisions about real documents.

Intended future use is controlled research on licensed receipt/form datasets.
Real identity documents, biometrics, forensic conclusions, autonomous rejection,
and production KYC decisions are out of scope.
